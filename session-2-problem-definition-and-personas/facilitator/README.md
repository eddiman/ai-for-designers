# Session 2: facilitator notes

Front-facing material for participants is in the session root `README.md`. This folder holds the facilitator-only guidance.

## Recap (open the session with this)

Whether participants continue from their own Session 1 output or pick up the premade reference versions, open with a recap that walks through the reference summaries:

- which prompt style produced each and why. The reference carried the **generic** summaries for the three interviews and the **directed** summary for the questionnaire (the choices recorded in `../premade/triangulation.md`), because those were the cuts that best held up across sources;
- what the central tension is, meaning reliability against personalization (see `../../session-1-research-synthesis/facilitator/research-design-notes.md`);
- why the summaries are solid enough to build on.

For returning participants the recap is a model for justifying their own work, and for drop-ins it's the context they need to use the premade versions.

## Running the three activities

The participant README gives starter prompts for all three activities (insights → problem definition → personas) and lets participants choose between one chat for the whole packet or a fresh chat per activity, with the evidence attached up front either way. Point out the trade-off, carry-over context against clean context, rather than prescribing one. The prompts here are meant to be adapted, unlike Session 1, so steer the room toward tuning them rather than copying them verbatim. The learning is in judging the output, meaning the evidence anchor, the hypothesis label, and the red-team response, rather than in the prompt mechanics.

Rough timeboxes for a live run:

- Recap + setup: 10 min
- Key insights: 10 min
- Problem definition (generate, rank, commit, red-team + response): 25 min
- Personas: 20 min
- Save the packet + wrap: 10 min

## Why personas are required here

Session 3 runs the UX review in character as these personas, so they're a working input the next session depends on. That is the reason they must be evidence-tied and hypothesis-labelled, and it is worth making explicit to the room.
