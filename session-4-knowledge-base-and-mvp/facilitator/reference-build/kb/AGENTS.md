# KB AGENTS

## Purpose

This directory stores durable knowledge for the bus-app project used throughout the course.

## Read order

Before making substantial changes, read:

1. `AGENTS.md`
2. `README.md`
3. `overview.md`
4. Relevant files in `decisions/`, `design/`, `stories/`, and `learnings/`

## Knowledge model

Raw imports belong in `sessions/`. Curated knowledge belongs in `overview.md`, `decisions/`, `design/`, `stories/`, and `learnings/`.

Raw files preserve their source material. Curated files are concise, evidence-linked records that should be updated deliberately.

## Folder semantics

- `overview.md`: current project entry point
- `decisions/`: decisions and their rationale
- `design/`: personas, design directions, flows, principles, and constraints
- `stories/`: intended user outcomes derived from the personas
- `learnings/`: research and review findings
- `sessions/`: raw imported artifacts
- `views/`: optional derived summaries; never canonical
- `templates/`: lightweight templates for new records

## Rules

1. Make the smallest correct update.
2. Update an existing curated record before creating a duplicate summary.
3. Keep evidence, inference, and decision distinct.
4. Do not treat an imported artifact as a decision unless a curated decision record says so.
5. Keep writing direct, factual, and easy to scan.
