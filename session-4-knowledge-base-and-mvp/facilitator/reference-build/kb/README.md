# Project knowledge base

This is the durable, markdown-first knowledge base for the bus-app project in **AI for Designers**.

Start with [overview.md](overview.md). It links to the committed problem, personas, prototype directions, and findings that should inform the MVP work.

## Raw and curated knowledge

- [sessions/](sessions/README.md) preserves the supplied research and design artifacts unchanged.
- [decisions/](decisions/README.md), [design/](design/README.md), [stories/](stories/README.md), and [learnings/](learnings/README.md) distil the durable information from those artifacts.
- [views/](views/README.md) is reserved for summaries derived from the canonical records.

Use the templates in [templates/](templates/) when a new durable record is needed.
